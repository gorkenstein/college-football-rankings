WEEKLY STANDINGS COLUMNS UPDATE

What changes
------------
- The standings now show a separate column for every scored football week.
- Because this pool began in football Week 6:
    pool week_id 1 -> Week 6
    pool week_id 2 -> Week 7
    pool week_id 3 -> Week 8
    and so on.
- A new week column appears automatically after that week's scores are published.
- Season Total remains at the far right and is the sum of all weekly scores.
- A dash means that player has no score for that week.
- When signed in, clicking a weekly score opens that exact player's scored ballot for that exact week.
- Clicking a player's name still opens their latest scored ballot.
- The scored-ballot week selector now uses labels such as:
    Week 6 · Oct 4, 2026
    Week 7 · Oct 11, 2026

Install
-------
GitHub only:
1. Replace index.html
2. Replace version.json

No Supabase SQL and no Edge Function changes are required.
